## Novedades v0.63.0 Preview

- **Bolero de Ravel** sigue integrado en bucle y sin descargas externas.
- La música se **pausa al minimizar o cerrar el panel** (con Digimon flotante activo) y **reanuda desde el mismo punto** al restaurarlo.
- La pausa manual se respeta; no se reinicia la música si estaba desactivada.
- Se conservan crianza, partidas, Quest, PvP, Bosses y personalización.

## Cómo actualizar

1. **Respalda tus partidas** antes de sustituir el ejecutable.
2. Si tienes la **v0.62.0 Preview**, abre **Configuración → Actualizaciones**, selecciona **Preview**, y usa **Buscar → Descargar → Instalar y reiniciar**.
3. También puedes descargar el nuevo EXE portátil desde la tabla y ejecutarlo manualmente. No necesitas instalar Electron ni Node.
4. Desde versiones anteriores a la v0.61.0, se recomienda pasar primero por la v0.61 para conservar el flujo de actualización reparado.

Las descargas se verifican por **SHA-256** antes de instalarse. Los nuevos ejecutables se publicarán en [GitHub Releases](https://github.com/xGonzalooo/Pendulum-PC-Update/releases).

Proyecto fan no oficial. Digimon y sus personajes pertenecen a sus respectivos titulares.
