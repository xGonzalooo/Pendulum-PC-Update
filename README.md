## Cómo actualizar

1. Conserva un respaldo de tus partidas.
2. Si ya tienes la **v0.61.0**, esta v0.62.0 permite probar el **actualizador automático reparado**: selecciona el canal Preview y usa Buscar → Descargar → Instalar y reiniciar. Para versiones anteriores a 0.61, instala manualmente la v0.61 primero.
3. Desde la **0.61.0**, abre **Configuración → Actualizaciones**, elige **Preview** y utiliza **Buscar, Descargar e Instalar y reiniciar** cuando aparezca una nueva versión.

Las descargas se verifican por **SHA-256** antes de instalarse. Los nuevos ejecutables se publicarán en [GitHub Releases](https://github.com/xGonzalooo/Pendulum-PC-Update/releases).
